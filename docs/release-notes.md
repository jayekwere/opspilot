OpsPilot 0.1.0 delivers ten operational diagnostic runbooks, an authenticated Python API and CLI, and a React and TypeScript operations console.

Independent approval gates disposable service recovery and temporary security-configuration repair. Runs retain sanitized evidence, findings, timing, intervention needs, safe replay semantics, and audit events. The lab demonstrates detection, approval enforcement, verified recovery, and refusal of stale approval.

Validation includes 98 passing macOS tests with one Linux-only skip, 99 passing Linux tests, 87.23% branch-aware host coverage, three browser workflows, actual TLS handshakes, a restricted-container recovery smoke test, live GitHub workflow collection, and failed/healthy Kubernetes deployments in a disposable cluster. Dependency audits and medium/high static security checks pass. Hosted verification results are linked from the repository.

The controlled benchmark records a scripted comparator and automated diagnostic timings. The scripted comparator is faster in this small lab. Human execution time and productivity gains remain unmeasured.

Remediation affects only lab-owned objects. Production fleet recovery, distributed workers, multi-tenant identity, and comprehensive provider posture analysis remain outside the validated scope. Review SECURITY.md and the runbook contracts before use.
